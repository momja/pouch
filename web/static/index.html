Saving links

From iOS (share sheet)

Add Pouch to your iPhone's share sheet with a one-time Shortcut:

  1. Open Shortcuts and create a new shortcut.
  2. Add the action Get contents of URL, and set its URL to:
  1. Tap the variable pill after url= and choose Shortcut Input.
  2. In the shortcut's settings, enable Show in Share Sheet (accept URLs & Safari pages), and name it "Save to Pouch".

Sharing any page → "Save to Pouch" now files it here.

From Android

Install Pouch (browser menu → Add to home screen). It registers as a share target, so it shows up directly in the share sheet.

From any desktop browser

Drag this bookmarklet to your bookmarks bar, then click it on any page:

➜ Pouch it

About

Pouch is a self-hosted client for Wallabag, built with the unofficial Go API wrapper wallabago.
